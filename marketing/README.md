# GatherSync Marketing Assets

This directory is intentionally separate from the app code so marketing and promotion assets do not get lost or mixed into product implementation work.

## Structure

- `rescued-site/`: recovered static marketing site from archived source, cleaned and made easier to iterate on.

## Usage

- Open `rescued-site/index.html` in a browser for local review.
- Deploy this folder as a standalone static site if desired.
- Primary production URL for this version: `https://app.gathersync.app`.
- Keep app feature work outside this directory.
- Email setup runbook:
  - `EMAIL_SETUP.md`

## Notes

- This is a baseline "rescued" version and can be improved over time.
- Mobile responsiveness is included as a first pass and should be validated on real devices.
